# 阅读速查表（示例）

> **本文件是「双版本制」演示的下半部分**：由 STANDARDS 单向浓缩而来，章节编号 1:1 对齐。规则细节见 [[examples/READING/READING-STANDARDS|规范原文]]。

## 1. 阅读前的准备

| 一句话规则 | 最短示例 |
|---|---|
| 先写问题再翻书 | 「我想知道：为什么我会读不下去？」 |
| 同主题先广后深 | 入门 ×2 → 深入 ×1 |
| 单次阅读定时间盒 | 25–50 分钟，超时记为下次起点 |

## 2. 阅读中的动作

| 一句话规则 | 最短示例 |
|---|---|
| 每章把标题变疑问句 | 「第 3 章 记忆曲线」→「记忆曲线怎么影响我的复习」 |
| 划线≠笔记，要复述 | 原文划线 + 一行自己的话 |
| 记录冲突点（比认同点值钱） | 「作者说间隔复习优于集中复习，但我考试靠集中复习更有效」 |
| 卡住先标记，10 分钟上限 | 标记 ⚠️ 继续读，读完再回头 |

## 3. 阅读后的沉淀

| 一句话规则 | 最短示例 |
|---|---|
| 三句话复述核心主张 | 写不出来 = 没读完 |
| 笔记先落 99-Inbox | 再跑 `vault-inbox-consolidate --apply` 晋级 |
| 48 小时内问「改变了哪个行为」 | 「下次复习先排间隔表」 |
