# Coding Vault Master Skill Router & Environment Detector

Intelligently detect workspace environment state and route developer intent to the optimal Coding Vault skill.

## 🧭 What This Skill Does

The `vault` skill is the main entry point for all Scriptorium Vault operations. It detects your workspace state and routes your intent to the right specialized skill. Whether you are starting a new project, designing architecture, debugging, or wrapping up a session, `vault` finds the best tool for the job.
